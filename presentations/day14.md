# What is AI Studio?

- Coding agent or vibecoding platform
- Give it a prompt in English and it will create a web app for you
- Use further prompts to refine the app, add features, and fix bugs

---

# Big Feelings

- Changing the way software engineering works
- Lower barrier to entry
- Easy to make custom software just for you!
